# Moppo 0.7.0

Build 57.

### Menu bar

- Show disk space, Trash readings, and the last Safe to Remove result with native macOS controls.
- Use **Reload** to refresh readings and scan for Cleanup items without opening the main window.
- Add **Delete Safe to Remove** with a new background scan and no confirmation.
- Show operation progress, results, access guidance, and **Stop** for operations that support cancellation.
- Keep work running when the panel closes. Add **Settings** access.

### Shortcuts

- Add actions for free space, Trash size, Safe to Remove size, and Cleanup scans.
- Return size values in bytes, with volume names, item counts, or scan dates in the response.
- Open Moppo for a requested scan.
- Add **Delete Safe to Remove** to scan and remove eligible items in the background without confirmation.
- Run background cleanup without opening the main window. Background cleanup requires Full Disk Access.
- Keep removal protection checks and the current receipt setting. No Shortcuts action empties the Trash.

### Duplicate files

- Add a **Keep** menu to choose the oldest copy, newest copy, shortest path, or copies in a folder.
- Save the selected rule between launches. Keep individual **Keep instead** choices when the rule changes.
- Show the selected rule on the **Keep** button.
- Keep the duplicate scan stage and file counter on separate lines. Use equal digit widths for the counter.

### Dashboard

- Show local Time Machine snapshots with their dates and an estimate of purgeable space.
- Add **Delete Snapshots…** to delete Time Machine local snapshots after confirmation.
- Read the snapshots again when you select **Refresh Dashboard**.

### Cleanup

- Keep sidebar navigation available during Cleanup removal and Trash emptying. Keep conflicting disk actions blocked.
- Show progress on the operation page and its status in other views.
- Keep Cleanup results after Put Back or removal in another view. Offer **Scan again** or **Continue** when data changes.
- Keep the notice about older results below the Cleanup controls. Keep the header and sidebar available.
- Reuse Trash results between visits. Read the Trash again after removal, Put Back, or **Refresh Trash**.
- Turn off scheduled scans by default. Keep saved schedule settings.
- Add **Put Back** to History for items with valid Trash receipts.
- Add **Put Back Run** to restore all available items from one recorded uninstall or cleanup run.
- Offer Composer, Bundler, and Go `vendor` folders for removal after tool, lockfile, and Git checks.
- Show open pull requests in Git worktree rows and reviews when the pull request matches the worktree commit.
- Confirm pushed worktree commits from saved remote branches when the local branch has no upstream.
- Accept ignored worktree files when the main checkout keeps an identical regular file of 1 MiB or less.
- Keep a worktree when the same cleanup would remove its matching main checkout files.
- Show each Docker volume as a separate row, with its size, container use, and Docker Compose project.
- Remove selected Docker volumes that no container uses. Moppo always asks before it removes a volume.
- Show **Not regenerable** on rows whose contents do not come back, such as Xcode Archives and application leftovers.
- Show the reason for **Not regenerable** in the label tooltip and to VoiceOver.
- Show the number of selected **Not regenerable** items in the removal confirmation.
- Show logs in `~/Library/Logs` as **Not regenerable** in Cleanup and App Uninstaller. **Safe to Remove** no longer selects them.
- Show protected AI Tools rows for GitHub Copilot CLI, OpenCode, Goose, OpenClaw, and Kiro.
- Show protected AI Tools rows for Devin, AnythingLLM, Cherry Studio, Comfy Desktop, and Stability Matrix.
- Show protected AI Tools rows for the Codex settings, credentials, databases, history, skills, installed packages, and desktop data.
- Show T3 Code desktop data in AI Tools. Keep all files of these tools protected, including cache folders.
- Show Ollama, Hugging Face, PyTorch, Whisper, and Keras models in folders that variables such as `OLLAMA_MODELS` and `HF_HOME` set.
- Keep models in a folder outside the home folder protected.
- Show the other folders in `~/.config` as separate Hidden & System Data rows.
- Protect toolchain, virtual machine, and credential folders in Hidden & System Data, such as `~/.rustup`, `~/.colima`, and `~/.aws`.
- Show the size of each protected folder. Offer only the caches in it that the developer tool catalog verified.
- Connect data folders that use another name to AnythingLLM, Cherry Studio, Stability Matrix, VoiceInk, T3 Code, DBeaver, and Superwhisper.
- Show these folders as user data with their application, in App Uninstaller, and in Application Leftovers after an uninstall.
- Show Homebrew database data folders as protected Hidden & System Data rows with their sizes.
- This applies to PostgreSQL, MySQL, MongoDB, Redis, OpenSearch, and Elasticsearch.
- Show `~/Library/DBeaverData` as protected data with DBeaver. Without DBeaver, Hidden & System Data shows it.
- Show the sizes of the protected Postgres.app and DBngin data folders under their applications.
- Keep the Postgres.app, DBngin, and DBeaver data folders in App Uninstaller and Application Leftovers.
- Moppo never offers database data, MySQL binary logs, or the data folder of an older PostgreSQL version.
- Show tool storage that Moppo did not scan before as protected Hidden & System Data rows with their sizes and owners.
- This applies to Podman machines, mise, NuGet, RubyGems, the cabal store, the Android SDK, DBngin versions, and ai-coustics models.
- Offer only the Podman image cache in these rows. Podman downloads it again at the next `podman machine init`.
- Show the Claude Code and Cursor CLI versions from the native installers as protected AI Tools rows.
- Show the cabal 3.16 package cache in `~/.cache/cabal` as a Package Manager Caches row that needs review.

### Command line and agents

### Fixes

- Show the T3 Code icon in **AI Tools**. Earlier versions showed an empty square.
- Show the OpenClaw icon in **AI Tools**. Earlier versions showed an empty square.
- Show a neutral symbol, not an empty square, for AI tools without an icon, such as GitHub Copilot CLI.
- Show launch agents and launch daemons that use another file name in App Uninstaller and Application Leftovers.
- Connect a launch file to its application only by its program path or its `AssociatedBundleIdentifiers` key.
- Connect the Comet updater agent to Comet, because `Comet.app` contains the updater that the agent names.
- Show **Stopping the removal** when you cancel a removal. Earlier versions showed **Stopping the wait**.
- Name each path that App Uninstaller keeps on disk, with its size and reason. Earlier versions showed a number.
- Show **Partial uninstall** when some related paths stay on disk. Earlier versions showed **Complete uninstall**.
- Remove a group container with its application when no other application claims it in its code signature.
- Show such a group container as user data in App Uninstaller.
- Keep a group container on disk when Moppo cannot read all of the code signatures.
- Add a checkbox to each shared group container in **Stays on Disk**.
- Remove a selected shared group container with its application. Moppo shows a warning first.
- Finish a scan when Spotlight does not reply. Earlier versions stopped at the first row.
- Show the file modification date in **Last opened** when Spotlight does not reply in 2 seconds.
